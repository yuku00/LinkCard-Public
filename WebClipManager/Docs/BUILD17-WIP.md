# build17：测试书签备份开发中

本版本只对用户选择且标题恰为 `WCM-DELETE-TEST` 的书签提供目录流式备份，不执行系统删除，也不会修改 Safari。复制按固定 64 KiB 缓冲、openat/O_NOFOLLOW 检查目录和普通文件；拒绝符号链接及硬链接；备份文件同步后原子发布 manifest，失败/取消时源文件不变。无完整 manifest 的 `.incomplete-*` 目录不是完成备份，可能占用空间。

**尚未完成，勿用作删除前唯一备份：**尚无回收站列表、恢复、清空、完整的源快照一致性保证、运行时 ABI/mock 或删除入口。尚未测试满盘和运行时取消；仅支持确认框取消，不支持复制进行中取消。复制还未保留全部源文件元数据。系统删除语义与受管状态不明，仍然拒绝一切删除。不得认为 backupOnly 表示已删除或图标可恢复。当前不可在界面管理或移除未完成备份。请勿用于实际个人数据。

本地合成：`python3 Tools/test_recycle_copy.py`（64 MiB 文件、字节摘要、非法 id、调用前取消、重名、符号链接及源不变）。无真实 iOS 私有删除运行测试。
