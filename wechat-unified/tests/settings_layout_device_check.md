# 设置页布局真机回归检查（iOS 16）

前提：将包含当前 Settings.m 的构建安装到测试设备；在微信内打开「整合」。不要清空设置或重置数据。逐项截图留证；以下任何文字、搜索框或列表内容相互遮挡均为失败。静态源码测试不能替代此检查。

1. 首次进入，停在列表顶部：状态栏、导航标题、完成按钮、搜索栏和首个分组/首行均可辨识，搜索栏与标题及列表不重叠。
2. 向下滚动到「语音」分组（与用户截图相同），再缓慢上下滚动：单元格滚出列表顶部时被裁切，不出现在导航标题、完成按钮或搜索栏后面；搜索栏仍可使用。截图。
3. 点击搜索并输入「语音」：键盘出现，搜索框和导航控件可见且不相互遮挡；结果可滚动，列表内容不覆盖导航区。切换一个可用开关，确认对应状态变化；恢复原值。取消搜索后，分组和原设置状态恢复。
4. 搜索「接口检测」，点击结果，确认进入宿主适配诊断页；返回后清空搜索，确认诊断入口仍可访问。
5. 分别在较大辅助功能字体、横屏（设备支持时）及深色模式重复第 1–3 项，确认无相互遮挡且控件可操作。恢复设备原设置。
6. 点击「完成」关闭页面，重新打开检查首屏。记录设备型号、iOS 版本、微信版本、构建标识、每项结果及截图；未执行标记为 NOT RUN，不得标记通过。
